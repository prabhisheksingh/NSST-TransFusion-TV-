# Choose a license before publishing

The repository currently has **no `LICENSE` file**, because redistribution terms are a decision for the code owner. Publishing code on GitHub **does not by itself grant others permission to reuse or redistribute it**.

Common choices for the original MATLAB files include:

- **MIT License:** permissive, with attribution and warranty disclaimer.
- **BSD 3-Clause License:** permissive, with an additional non-endorsement clause.
- **GNU GPL v3:** copyleft, generally requiring derivative redistributions to remain GPL-compatible.
- **No license / all rights reserved:** source may be viewable but reuse rights are restricted; less convenient for reproducible research.

Before selecting a license, verify **your ownership and any university, collaborator, funder, or third-party IP requirements**. If an existing journal/article agreement applies, check it as well.

**External NSST code is NOT included.** Any NSST toolbox, its filters, and its supporting code may be covered by separate licenses; do not assume they can be redistributed with this project.

After choosing a license, add a file named `LICENSE` at the repository root using the exact official license text, the proper year, and the owner/copyright holder as appropriate. Amend this document and the README to reflect the selected license.
